**DRF Authentication & Permissions**

**Authentication** (Who is this user?)
- Basic Authentication (username and password)
- Session Authentication (secure session)
- Token Authentication (Unique Token)
- JWT Authentication (JSON Web Token, best method use it in large applications)

**Permissions** (What is the user allowed to do?)
- `AllowAny` (All are allowed to access the API)
- `IsAuthenticated` (Only logged in users can access the API)
- `IsAdminUser` (Only admin users can access the API)
- `IsAuthenticatedOrReadOnly` (logged in users can access all API but read-only for others)

What is a Cookie?
Client-side storage: Data lives right inside your web browser on your device.
Small capacity: Each cookie can hold up to 4KB of data (good for lightweight info).
Lifespan: Can be short-term or set to persist for months/years until an expiration date.
Common uses: Remembering dark/light mode preferences, language choice, or tracking site analytics.
