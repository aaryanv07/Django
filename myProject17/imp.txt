**Introduction to Django REST Framework**

- What is REST API (Representational State Transfer Application Programming Interface)
(A way to communicate between two applications or systems i.e client and server with 
HTTP methods GET,POST,PUT,DELETE,PATCH)

**DRF Key Features:**

- JSON, XML, or YAML data
- Decoupled backends, mobile APIs, Microservices
- Models, Serializers, and ViewSets
- Browsable Web API (for live endpoint testing)
- Installation and setup step-by-step
- Create first simple API (`GET` request)
- Run and test API in browser or Postman (Thunder Client)

- What is Django REST Framework (A framework that makes it easier to build Web APIs)
- Why use DRF (Because it provides the serializer,authentication,authorization,request/response 
viewsets,routers etc.)

**Update API in Django REST Framework**

- PATCH API (partial update i.e only updating specific fields)
- Modify all data and update specific data based on ID
