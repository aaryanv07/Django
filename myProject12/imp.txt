**User Authentication**

- Built-in Django auth system --> installed apps --> "django.contrib.auth" (ready made login in logout)
- User registration form
- Login, logout
- Hashing passwords (secure) --> in db.sqlite file (auth_user) --> pdkdf2 format and has salt method 
- Restricting pages for logged-in users
- `@login_required` decorator --> hides the page without the user

steps -->
create an app accounts --> configure it (midleware should have auth middleware)

setup --> urls.py , forms.py

create templates folder --> accounts folder --> base.html , register.html , login.html , dashboard.html

commands --> python manage.py makemigrations accounts --> python manage.py migrate

create superuser

python manage.py createsuperuser -- username -- admin -- email -  admin@admin.com --
